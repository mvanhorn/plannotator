# Source line numbers in plan / annotate

Real `plannotator annotate` session on a sample Markdown file (heading, multi-line paragraph, list, fenced code, table). Temp `PLANNOTATOR_DATA_DIR`, browser auto-open disabled.

1. Setting off: no gutter.
2. Options → Settings → Display.
3. Source line numbers on.
4. Gutter labels on the document (`1`, `3–5`, `7`, `8`, `10–15`, `17–20`).
5. Select “thirty seconds”, comment, save. Annotation still quotes the selected words; labels stay out of the quote.

`out.mp4` is a 24s 1920×1080 30fps H.264 still sequence of those screenshots. `preview.gif` is the same 24s at 720×405 12fps.
